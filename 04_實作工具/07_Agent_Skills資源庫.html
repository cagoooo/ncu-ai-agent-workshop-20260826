建議的三步使用方式

把「下載大神版本」變成「和 Agent 一起長出自己的版本」。

01｜先讀再裝

先看 README、SKILL.md、LICENSE、references 與 scripts；確認它要做什麼，以及會讀取哪些檔案或使用哪些命令。

02｜用小任務試跑

用合成資料或可逆的練習專案測試，不要一開始就交出個資、正式研究資料或發布權限。

03｜改成自己的 Skill

補上你的工作流程、輸出格式、驗收條件與人工停點，再用跨平台 Skill 驗證器檢查可攜性。

安裝前的信任邊界

外部 Skill 等同於 Agent 會讀取的操作手冊，可能包含指令、腳本或外部連線建議。這個資源庫只做公開索引，不替任何第三方 Skill 背書。

  • 先確認作者、Repo、LICENSE、最近維護狀態與權限需求。
  • 搜尋是否要求 API key、token、私鑰、上傳檔案、刪除資料或略過人工確認。
  • 不把學生個資、研究原始資料、API key、token 或密碼放進 Skill 或 Git 歷史。
  • 高風險的發布、刪除、寄送、改權限與正式評分仍需 Human-in-the-loop。
