國立中央大學 AI 教學與研究工作坊｜正式研習包 v1.18（手機平板 RWD 與全螢幕優化版）
活動日期：2026-08-26
講師：黃凱揚（阿凱老師）｜桃園市龍潭區石門國民小學

開始方式
1. 雙擊「START_HERE_研習資源導航.html」。
2. 講師開啟「01_簡報」中的上午或下午正式簡報。
3. 學員開啟「02_學員任務書／學員手把手操作任務書.html」。
4. 若網路或帳號受限，改用「03_起始成果包」與「07_備援」。

主要資料夾
- 01_簡報：上午、下午正式 PowerPoint；所有操作連結旁均配置可投影掃描的 QR Code。
- 02_學員任務書：網頁版與 PDF 任務書。
- 03_起始成果包：Gemini Notebook、Gem、Canvas、Agent Skill 起始材料。
- 04_實作工具：PIRLS 工作台、Skill 產生器、跨平台 Skill 驗證器、Agent 證據打包器、123 案例篩選器、部署選擇精靈、提示詞面板。
- 05_範例資料：PIRLS 風格合成資料、資料字典、講師參考編碼與 Akai 123 筆工具目錄快照。
- 06_場務與驗收：帳號、彩排、時間備援、資料治理、平台、PowerPoint 與 QR Code 連結稽核。
- 07_備援：簡報與講義 PDF，另有 `index.html` 線上備援入口，可直接分享給社群成員。
- 08_HTML簡報：可直接放到 GitHub Pages 的互動式 HTML 簡報；開啟 `index.html` 選擇上午或下午場。上午 35 頁、下午 44 頁；主導覽板另提供 10 個分支入口（資源導航、任務書、PIRLS、Skill 驗證、123 案例、部署精靈、提示詞面板、場務手冊、備援與 Canvas 起始站）。投影片舞台在手機／平板會垂直置中並依可視高度最大化，橫向連結列與導覽控制不覆蓋內容；全螢幕按鈕支援原生 Fullscreen API，iOS／嵌入式瀏覽器則自動切換可退出的沉浸模式。
- GitHub Pages 線上版：https://cagoooo.github.io/ncu-ai-agent-workshop-20260826/
- QR Code 稽核：`06_場務與驗收/QR_Code連結稽核.md`；共 122 個碼，1280×720 投影版解碼 122/122 通過。
- 桌機顯示：HTML 簡報會依可視高度放大舞台；按工具列「全螢幕」或鍵盤 `F` 後隱藏工具列與導覽，舞台會依螢幕比例使用全寬／全高呈現，投影片字級也會同步放大。
- 投影片互動：每頁投影片中的平台文字、案例連結、資源卡片網址與 QR Code 均已建立可直接點擊的透明互動區；全螢幕模式也能直接開啟連結。
- 深色模式：下午場轉場已清除上一頁殘留動畫，避免文字重疊殘影；連結、控制列與提示文字同步提高對比，降低投影與全螢幕觀看時的閱讀負擔。
- 流程圖版型：上午／下午流程頁改為步驟卡片、明確連接箭頭與底部驗收帶；下午示範頁新增「人在迴路」控制點，補足 Agent 提案、教師核准、測試驗證與交付決策。
- 品牌識別徽章：Antigravity、Codex 與 GitHub Pages 在對應章節／部署頁加入簡報化識別徽章，保留 QR Code 與直接點擊連結。

- 返回導覽：所有實作工具、學員任務書、場務手冊、備援頁與 Canvas 起始站均在首屏提供「回到簡報主頁」按鈕；從任一分支返回後，可直接再選擇上午／下午場次或其他分支入口。
- 網站更新機制：Service Worker 網路優先 HTML、版本輪詢與新版浮動提示；網站版本記錄於 `version.json`，目前為 `2026.08.13.17`。

資料安全
- 本機 HTML 工具不呼叫 AI API，也不需要 API key。
- PIRLS 工作台只在瀏覽器記憶體處理資料，重新整理即清除。
- 使用自己的 ChatGPT 或 Gemini 做 AI 初編前，必須先完成去識別化。
- AI 初編不得取代教師或研究者的人工最終判定。

尚需外部確認
- 中央大學現場 Wi-Fi、投影、裝置與安裝權限。
- 六位教授活動日前的實際登入與功能權限。
- 活動前 7 天與 24 小時的平台、連結與介面複核。

以本資料夾中的 START_HERE 與 01_簡報為唯一正式入口。外層或 ARCHIVE 中檔案僅供建置與回溯。
