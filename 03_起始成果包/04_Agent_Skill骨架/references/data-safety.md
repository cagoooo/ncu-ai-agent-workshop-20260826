# 教學與研究資料安全

## 輸入前

- 確認分析單位與必要欄位，只保留完成任務所需資料。
- 將姓名、學號、電子郵件、班級座號及自由文字中的可識別線索移除或代碼化。
- 優先使用合成資料；真實資料需符合校內規範、同意與保存期限。
- 不把 API key、密碼、權杖或私密網址放入提示詞、前端程式或公開儲存庫。

## 分析時

- 先檢查欄位、型別、缺漏、重複、允許值與樣本數。
- 選擇題與簡答題分流；不要用同一方法處理。
- 保存 AI 初編、證據、理由、信心與待人工複核旗標。
- 不把小樣本差異、相關或模型輸出誇大為因果結論。

## 交付前

- 抽查極端、低信心、空白與邊界案例。
- 最終碼由人工另欄確認，保留歧異理由與版本。
- 公開前再次掃描姓名、檔名、畫面、通知、網址與中繼資料。
- 清楚標示合成資料、研究限制與未確認項目。
